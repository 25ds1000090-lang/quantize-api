# Quantize Candidate Admission API

Vercel-ready FastAPI implementation of `POST /quantize`.

## Deploy

1. Create a GitHub repository and upload the **contents** of this folder.
2. Import that repository in Vercel and deploy with default settings.
3. Submit the Vercel project URL (for example `https://your-project.vercel.app`).

The endpoint is `POST /quantize`; opening it in a browser uses GET and may show
`Method Not Allowed`, which is expected.
